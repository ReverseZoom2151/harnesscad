# harnesscad hardcorpus

hard corpus: score a real model on the held-out split and print BOTH columns -- the field's weak grader and the measured oracle -- plus the gap between them

## Usage

```bash
harnesscad hardcorpus [--model <model>] [--limit <limit>] [--out <out>] [--cache <cache>] [--seed <seed>] [--temperature <temperature>] [--max-attempts <max_attempts>] [--max-tokens <max_tokens>] [--no-resume] [--reference] [--no-models] [--report <report>] [--full-board] [--json]
```

## Arguments

- `--model`: ollama model to score; repeat to score several (default: qwen3.6:27b, ornith:9b)
- `--limit`: score only the first N held-out briefs (0 = all). A smoke-test knob: a limited run is reported with its own smaller n and is cached as a different cell from the full sweep. (default: 0)
- `--out`: write/append the submissions JSON here (resumable) (default: hardcorpus_results.json)
- `--cache`: directory for the model-output cache (resume is free and byte-identical) (default: .hardcorpus_cache)
- `--seed`: model seed (recorded in the results file) (default: 20260819)
- `--temperature`:  (default: 0.0)
- `--max-attempts`: model calls per brief; attempts after the first exist only to repair an UNPARSEABLE response (default: 2)
- `--max-tokens`: completion budget per call (default: 2048). A reasoning model spends this thinking before it reaches the array, and a truncated array is an INVALID attempt. NOTE: the completion cache is keyed by model+seed+temperature+attempt+messages and NOT by this, so point --cache somewhere fresh when you change it. (default: 2048)
- `--no-resume`: ignore any existing cells in --out and re-run them
- `--reference`: also score the corpus's own reference solutions -- the ceiling and the self-test; needs no model
- `--no-models`: run no model at all (use with --reference)
- `--report`: print the board for an existing results file and exit
- `--full-board`: print the whole leaderboard, including the near-miss and contract-residual proofs (needs the exact kernel and is slow)
- `--json`: emit the submissions/board as JSON
